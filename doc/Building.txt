Building ECT (Rust)
===================

This branch (`rust`) contains the pure Rust implementation of ECT. All
dependencies are pure Rust, so no C compiler, CMake or NASM is required.
The C/C++ and Go implementations live on the `cpp` and `go` branches.

Requirements:
- Rust 1.88+ with Cargo (https://rustup.rs)

Build the CLI:

    cargo build --release

The binary is written to target/release/ect (ect.exe on Windows). The
release profile enables LTO, a single codegen unit and symbol stripping.

Checks used by CI (.github/workflows/rust.yml):

    cargo fmt --check
    cargo clippy --all-targets --locked -- -D warnings
    cargo test --locked
    cargo +1.88 check --all-targets --locked     # MSRV

Benchmark:

    cargo run --release --example zip_bench

Cross-compilation, e.g. Windows ARM64 from Windows x64 (needs the MSVC
ARM64 build tools):

    rustup target add aarch64-pc-windows-msvc
    cargo build --release --target aarch64-pc-windows-msvc

Project layout:
- src/lib.rs        library entry point (`ect::process`, `Config`, `Report`)
- src/processor.rs  path collection, worker pool, per-format dispatch
- src/detect.rs     format detection
- src/png_opt.rs, src/jpeg.rs, src/webp.rs, src/gzip.rs, src/zip_opt.rs
                    format specific optimizers
- src/replace.rs    temporary files and atomic replacement
- src/main.rs       the `ect` command line tool
- tests/            end-to-end tests on real files
- examples/         benchmarks

Releases: pushing a `rust-vX.Y.Z` tag runs .github/workflows/release.yml,
which builds Windows/macOS/Linux binaries for amd64 and arm64 and
publishes them.
