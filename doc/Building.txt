Build ECT (Go)
==============

ECT is now built with Go.
No CMake/NASM toolchain is required.

Requirements:
- Go 1.22+

Build:
```bash
go build ./...
```

Run from source:
```bash
go run ./cmd/ect -help
```

Project layout:
- `pkg/ect`: importable Go library
- `cmd/ect`: CLI wrapper around `pkg/ect`
